# Contextual Rules: Postprocess Libraries

These rules apply to all files under `custom_library/postprocess_library/`.

## Naming Conventions

- **Directory**: `<ModelName>/` — matches the model name from model_list.json
- **Source file**: `postprocess_<model_lower>.cpp`
- **Header file**: `postprocess_<model_lower>.h` (optional)
- **Build output**: `libpostprocess_<model_lower>.so`
- **Install path**: `/usr/local/share/gstdxstream/lib/`

## Build System

All postprocess libraries use Meson:

```
<ModelName>/
  meson.build
  postprocess_<model>.cpp
  postprocess_<model>.h  (optional)
  builddir/              (generated by meson setup)
```

Build commands:
```bash
meson setup builddir
ninja -C builddir
sudo ninja -C builddir install
```

## Function Export

- Every library MUST export a `PostProcess` function with C linkage
- Use `extern "C"` to prevent C++ name mangling
- The function name must match the `function-name` property on DxPostprocess

```cpp
extern "C" void PostProcess(
    DXInferOutputMeta* output_meta,
    DXObjectMetaList* object_list,
    int width, int height);
```

## Code Standards

- C++17 standard (`cpp_std=c++17` in meson.build)
- Include confidence threshold and NMS threshold as static constants
- Handle edge cases: empty output, malformed tensor data
- No memory leaks: all allocations must be freed or managed by the caller
- Thread-safe: the function may be called from multiple GStreamer threads

## Testing

```bash
# Verify .so exports PostProcess
nm -D builddir/libpostprocess_<model>.so | grep PostProcess

# Verify no unresolved symbols
ldd builddir/libpostprocess_<model>.so | grep "not found"
```
